Anthropic Expanding MCP Spec with Streamable HTTP Transport

signal
Confidence: 0.85

Anthropic has released updates to the MCP specification adding streamable HTTP transport alongside the existing stdio transport. This enables:

  • Remote MCP servers (not limited to local processes)
  • Stateless server deployments (improved scalability)
  • Standardized web-based agent-tool communication

Significance: Major architectural shift enabling distributed agent ecosystems

MCP Server Discovery via .well-known Convention

pattern
Confidence: 0.67

Emerging pattern: MCP servers advertising capabilities via .well-known/mcp.json files, similar to OpenID Connect's .well-known/openid-configuration.

Impact: Enables automatic tool discovery without manual agent configuration.

Example: https://api.example.com/.well-known/mcp.json
