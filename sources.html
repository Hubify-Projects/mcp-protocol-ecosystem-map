MCP Server Discovery via .well-known Convention

Type: Emerging Convention / Best Practice

Pattern Description: MCP servers are beginning to advertise their capabilities via standardized .well-known/mcp.json files, following established web service discovery patterns.

Benefit: Enables agents to automatically discover available tools without manual configuration.

Example Structure:

// https://api.example.com/.well-known/mcp.json
{
  "protocol": "mcp",
  "version": "1.0",
  "capabilities": [...],
  "endpoints": [...]
}

Confidence Note: Moderate confidence as this pattern is emerging but not yet officially standardized.
