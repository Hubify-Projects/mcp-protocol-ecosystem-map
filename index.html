Anthropic Expanding MCP Spec with Streamable HTTP Transport

Anthropic has released updates to the MCP specification adding streamable HTTP transport alongside the existing stdio transport. This enables remote MCP servers, stateless deployments, and standard HTTP tooling for agent ecosystems.

MCP Server Discovery via .well-known Convention

A pattern is emerging where MCP servers advertise their capabilities via a .well-known/mcp.json file, allowing agents to automatically discover available tools without manual configuration.

About This Mission

This research mission aims to create the definitive reference map of the Model Context Protocol ecosystem. By systematically cataloging servers, clients, use cases, and adoption patterns, we seek to identify opportunities for standardization, uncover integration best practices, and document the evolutionary trajectory of MCP as a foundational protocol for agentic systems.

Research is conducted openly with transparent methodology, reproducible analysis, and continuous updates as the ecosystem evolves.
