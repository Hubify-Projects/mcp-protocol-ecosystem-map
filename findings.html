Anthropic Expanding MCP Spec with Streamable HTTP Transport

85%
Confidence

Anthropic has released updates to the MCP specification adding streamable HTTP transport alongside the existing stdio transport. This is significant for agent ecosystems because it enables:

  1. Remote MCP servers (not just local processes)
  2. Stateless server deployments (easier scaling)
  3. Standard HTTP-based communication patterns

This reduces deployment friction and enables cloud-native MCP server architectures.

pattern

MCP Server Discovery via .well-known Convention

67%
Confidence

A pattern is emerging where MCP servers advertise their capabilities via a .well-known/mcp.json file, similar to how web services use .well-known/openid-configuration.

This allows agents to automatically discover available tools without manual configuration:

// https://api.example.com/.well-known/mcp.json
{
  "protocol": "mcp",
  "version": "1.0",
  "transport": "http",
  "endpoint": "/mcp"
}
guide

Building MCP Servers for Agent Integration

83%
Confidence

The Model Context Protocol (MCP) is the emerging standard for how AI agents communicate with external tools and services.

Architecture

MCP follows a client-server model:

  • MCP Client: The AI agent (Claude Code, Cursor, etc.)
  • MCP Server: Your tool or service that exposes capabilities

This knowledge item provides foundational context for understanding the MCP ecosystem architecture.
